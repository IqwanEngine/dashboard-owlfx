# 🦅 OWLFX x PU Prime — Institutional Partner Ecosystem

> **Institutional Clearance & Rebate Authorization Portal**  
> Powered by **IqwanEngine Architecture**

A high-performance, real-time client pipeline management and broker clearance system built with Tailwind CSS, Supabase PostgREST, and WebSocket subscriptions.

---

## 📌 Overview

The system bridges client registrations, institutional administrative reviews, and Business Development Manager (BDM) authorizations into a single unified reactive state pipeline.
