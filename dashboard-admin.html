Standard SOP
1 Client Registration (daftar.html)

Client submits 4 fields (Full Name, Email, Phone, State). Database initializes record with status: 'New' and action_status: 'New'.

2 Admin Review (Dashboard Utama)

Data baru terus masuk dalam Admin Dashboard dengan status biru 'New'. Rekod ini kekal disembunyikan daripada Dashboard BDM sehingga dihantar ke proses seterusnya.

3 Remark Assignment & Confirmation

Untuk tukar status dia, Admin perlu klik ikon pensel, pilih remark dropdown, dan sahkan melalui [✓]:

• Kalau pilih $14USD / 1Lot status akan jadi 'Submit to BDM' (Data akan terus masuk dalam Dashboard BDM.).

• Kalau pilih No Rebate, Not Register Yet, atau Others status akan jadi 'Completed' dan akan muncul Tarikh Update di column sebelahnya..

4 BDM Queue & Resolution

Hanya rekod Submit to BDM akan masuk ke Dashboard BDM dengan status kuning 'Pending'. Apabila BDM klik [✓ Complete], status berubah menjadi 'Completed' (Hijau) di kedua-dua Dashboard beserta tarikh dan masa update.
